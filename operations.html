Windows Task Scheduler XML Deployment & Manual Control Guide

All tasks are defined using Windows Task Scheduler v1.4 XML schemas located in operations/xml/. You can register, query, or manually trigger all pipelines via PowerShell:

⚡ Automated Registration (PowerShell & schtasks)

Run the provided installer script in PowerShell to register all 5 XML pipelines directly using native Register-ScheduledTask and schtasks /create: 

powershell -ExecutionPolicy Bypass -File operations/install_tasks.ps1

Individual CLI Registration (Windows schtasks):
schtasks /create /tn "growgarden_01_premarket_screener" /xml "operations/xml/schedule_premarket.xml" /f
Individual PowerShell Registration:
Register-ScheduledTask -TaskName "growgarden_01_premarket_screener" -Xml (Get-Content "operations/xml/schedule_premarket.xml" -Raw) -Force
Verify Active Tasks:
Get-ScheduledTask -TaskName 'growgarden_*' or schtasks /query /fo table | findstr growgarden

🛠️ Direct Manual Trigger Commands

Execute any job on demand without waiting for the scheduler:

• Pre-Market Screener (Morning): .venv/Scripts/python.exe operations/run_premarket.py
• Live Intraday Engine (Market): .venv/Scripts/python.exe operations/run_intraday_live.py
• Reliance Reconciler (Evening): .venv/Scripts/python.exe operations/run_postmarket_assessment.py
• Nightly Backtester (Evening): .venv/Scripts/python.exe operations/run_backtests.py
• Dashboard Synchronizer: .venv/Scripts/python.exe operations/run_dashboard_sync.py
